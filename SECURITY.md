# Security Policy

## Supported version

Security fixes target the current default branch and live deployment.

## Reporting a vulnerability

Please use this repository's GitHub private vulnerability reporting flow. Do
not open a public issue containing exploit details, private data, or credentials.

Include the affected route or file, reproduction steps, impact, and a suggested
mitigation when available. Reports are reviewed before public disclosure.

## Security boundary

The application is static and local-first. It has no account system, backend API,
database, payment flow, or application telemetry. Learner progress remains in
browser storage. This policy does not make the independently authored educational
content official or certified.
